🌧 Rainfall Prediction in India 📌 Project Overview

This project predicts rainfall across 20 major Indian cities using recent weather data (2023–2025). It uses machine learning models to analyze temperature, humidity, wind speed, and other features to forecast rainfall trends.

📂 Repository Contents

📒 Rainfall Predection.ipynb → Jupyter Notebook with full workflow

📊 indian_20cities_weather_2023_2024.csv → Dataset used for training and testing

📘 README.md → Project description (this file)

📦 requirements.txt → Required Python libraries

⚙ Tech Stack

Python 🐍

Pandas / NumPy → Data preprocessing

Matplotlib / Seaborn → Data visualization

Scikit-learn → Machine learning models

Jupyter Notebook → Development environment

🚀 How to Run

Clone this repository

git clone https://github.com/YourUsername/rainfall-prediction-india.git cd rainfall-prediction-india

Install dependencies

Open the notebook

jupyter notebook "Rainfall Predection.ipynb"
